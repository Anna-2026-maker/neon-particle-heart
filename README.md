# Neon Particle Heart / 霓虹粒子爱心

一个由高密度荧光粉色粒子组成的互动爱心特效。爱心覆盖在持续滚动的 Python 代码背景上，并带有缓慢呼吸、粒子漂浮、霓虹辉光、点击波纹和长按拖拽散开效果。

An interactive neon heart made from dense glowing pink particles, layered over continuously scrolling Python code. It features slow breathing motion, drifting fragments, neon bloom, click ripples, and press-and-drag particle scattering.

## Features / 功能

- 高密度荧光粉色粒子爱心 / Dense glowing pink particle heart
- 缓慢呼吸式缩放和自然漂浮 / Slow breathing and organic particle drift
- 点击产生一次粒子波纹 / Click or tap to create a particle ripple
- 长按鼠标或手指拖拽，持续拨散粒子 / Press and drag to scatter particles continuously
- 松开后粒子自动回流并重组爱心 / Particles flow back and rebuild the heart after release
- 深色背景与滚动 Python 代码 / Dark background with scrolling Python code
- 暂停、重新聚合与全屏控制 / Pause, rebuild and fullscreen controls
- 响应式电脑与移动端布局 / Responsive desktop and mobile layout
- 无框架、无构建步骤 / No framework and no build step

## Usage / 使用

### Web version / 网页版

直接打开 `index.html`，不需要安装任何依赖。

Open `index.html` directly. No dependencies are required.

### Python version / Python 版

```bash
python -m pip install pygame
python effect.py
```

快捷键：`Space` 暂停，`R` 重新聚合，`S` 保存完整画面，`T` 导出透明底爱心图层，`Esc` 退出。
