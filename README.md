# Neon Particle Heart / 霓虹粒子爱心

由霓虹粒子构成的爱心循环动画，包含粒子聚合、呼吸旋转、蓄能爆发、烟花消散和反向回流重组。

A looping neon-particle heart animation featuring assembly, breathing rotation, charged explosion, firework fading and reverse-flow reconstruction.

## Features / 功能

- 密集粉紫色霓虹粒子爱心 / Dense pink and violet neon-particle heart
- 聚合、旋转、爆发、回流循环 / Assemble, rotate, explode and return loop
- 点击触发爆发 / Click to trigger the explosion
- 暂停与重新播放 / Pause and replay controls
- 滚动 Python 代码背景 / Scrolling Python-code background
- 响应式电脑与移动端布局 / Responsive desktop and mobile layout

## Usage / 使用

直接打开 `index.html`。无需安装依赖。

Open `index.html` directly. No dependencies or build step are required.
